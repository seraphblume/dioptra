# v0.3 engine specification

Status: **implemented, running in shadow mode.** The locked study prediction still comes from frozen v0.2.0 (see the [freeze contract](v0.2-freeze.md)). v0.3 is computed on every case, stored under `shadow`, and scored in the engine-comparison export.

Code: `js/engine-v03.js` · configuration: `js/config-v03.js` · tests: `tests/v0.3-engine.test.js`.

## Inputs

v0.3 accepts the v0.2 input unchanged, plus optional fields:

```js
{
  age,
  instrument: { vertexMm, pdDistanceMm, pdNearMm },
  near: { workingDistanceCm, nearPointCm },
  od: {
    sphere, cylinder, axis, va, pinhole,          // selected line (same as v0.2)
    readings: [{ sphere, cylinder, axis, reliability }],
    keratometry: { k1D, k1Axis, k2D, k2Axis }
  },
  os: { ... }
}
```

The selected line is required for both eyes; without it the engine abstains. Every other field is optional.

## Pipeline (per eye)

### 1. Normalize

- Convert plus-cylinder input to minus-cylinder form.
- Normalize axis to 1–180°.
- **Vertex distance.** If `vertexMm` differs from `vertex.targetMm` (12 mm), convert each principal meridian with F' = F / (1 − dF) and rebuild S/C/A. When no vertex distance is entered, 12 mm is assumed and an info flag says so.

### 2. Aggregate the readings

Every reading becomes a power vector (M, J0, J45). Three candidate centres are computed:

| Estimator | Definition |
|---|---|
| `selected` | The line the instrument marks as its result |
| `median` | Component-wise median of the repeat readings (the selected line is not double-counted; it is used only when no repeats were entered) |
| `mostPlus` | The repeat reading with the highest M; ties go to the one nearest the median in the J0/J45 plane |

`estimator` in the configuration picks the one that drives the prediction (default `median`). All three are predicted and stored, so they can be compared later without re-running.

Repeatability evidence: the range of M, the largest distance of a reading from the centre in the J0/J45 plane, and the vector distance between the selected line and the median.

### 3. Stratified spherical offset

- The refractive state comes from the **raw** centre M: myopia/emmetropia ≤ +0.50 D < low hyperopia ≤ +2.00 D < higher hyperopia.
- Age band: under 40, or 40 and over.
- `offset = sphereOffsets[state][band]`, capped at ±`maxOffset` (0.50 D).
- The offset is added to M only, so it never changes cylinder or axis.

All six strata start at −0.25 D, the v0.2 global value. Until they are fitted, v0.3 differs from v0.2 only through the estimator, vertex handling, axis precision and SE-preserving rounding.

### 4. Optional low-cylinder rule (off)

If `lowCylinder.dropAtOrBelow` is set (e.g. 0.25), any cylinder at or below it is removed and M is kept. That is the same as moving half the cylinder into the sphere. This is a hypothesis switch for testing.

### 5. Back to S/C/A, rounding and axis

```text
C = −2·√(J0² + J45²)
A = ½·atan2(J45, J0)   (mapped to 1–180°)
S = M − C/2
```

- The cylinder is rounded to 0.25 D first. The sphere is then rounded from `M − C_rounded/2`, so the predicted SE stays within half a step of the target M.
- Ties round toward +∞: more plus sphere, less minus cylinder.
- Axis is 1° when |C| ≥ 0.75 D and 5° below that. With zero cylinder, axis is written as 180.

### 6. ADD

- `ageTable` = the frozen v0.2 table, indexed by the **raw** refractive state of each eye; the larger eye value is used. (v0.2 indexes it by the offset prediction, which can move a hyperope across a bin boundary.)
- When `ageTable > 0` and a working distance is entered, the ADD changes by 100/WD − 100/40 D. It is rounded to 0.25 D and capped at +3.50 D.
- Reported only: the amplitude-based estimate, max(0, demand − amplitude/2), where amplitude = 100 / near point (cm) measured through the distance correction.

### 7. Flags

| Code | Level | Trigger |
|---|---|---|
| `VERTEX_ASSUMED` | info | No vertex distance entered |
| `VERTEX_CONVERTED` | info | Readings converted to 12 mm |
| `AR_REPEATS_MISSING` | info | Only the selected line entered |
| `AR_REPEATABILITY_LOW` | review | Range of M > 0.50 D (provisional) |
| `AR_ASTIGMATISM_UNSTABLE` | review | A reading > 0.25 D from the centre in J0/J45 (provisional) |
| `AR_SELECTED_OUTSIDE_CLUSTER` | review | Selected line > 0.25 D (vector) from the median (provisional) |
| `OFFSET_CLAMPED` | review | Configured offset exceeds `maxOffset` |
| `SE_SHIFT_REVIEW` | review | Prediction moves SE > 0.50 D from the selected line |
| `LOW_CYLINDER_DROPPED` | info | Low-cylinder rule applied |
| `OBLIQUE_ASTIGMATISM` | info | Axis 31–59° or 121–149° with \|C\| ≥ 0.75 D |
| `KERATOMETRY_DISAGREEMENT` | review | Autorefractor astigmatism differs from the simplified-Javal estimate by > 0.75 D (provisional) |
| `PINHOLE_LIMITED_GAIN` | review | VA worse than 20/30 with no pinhole improvement |

Case status: `insufficient_evidence` if any flag abstains, `review` if any review flag fires, otherwise `supported`. This is not a probability.

Simplified Javal, in vector form: total astigmatism = corneal astigmatism (minus cylinder along the flat meridian) + 0.50 D against-the-rule residual. That gives "−0.50 D with the rule, +0.50 D against the rule", and handles oblique corneas consistently.

## Output

The output has the same shape as v0.2 (`od`/`os` with `sphere`, `cylinder`, `axis`, `sphericalEquivalent`, `seShiftFromAR`, `seGuardrail`, `raw`, `vectors`, plus `tentativeAdd`), so it can replace v0.2 without changing the study CSV. It adds `engine`, `estimator`, `candidates`, `stratum`, `axisStep`, `ametropia`, `astigmatism`, `evidence`, `keratometry`, `flags`, `add` and `status`.

## Scoring (`js/scoring.js`)

- Sphere, cylinder and SE errors, and whether each is within 0.25 D.
- Power-vector error (ΔM, ΔJ0, ΔJ45), its magnitude, and astigmatic error 2·√(ΔJ0² + ΔJ45²).
- Axis tolerance by the clinician's cylinder, following ANSI Z80.1: ≤ 0.25 D ±14°, ≤ 0.50 D ±7°, ≤ 0.75 D ±5°, ≤ 1.50 D ±3°, above ±2°. Not scored when either cylinder is zero.
- `clinicalMatch` = sphere and cylinder within 0.25 D and axis within tolerance (where applicable).

## Fitting the offsets (`tools/fit-offsets.js`)

```sh
node tools/fit-offsets.js <study-or-shadow.csv> [--prior 8] [--base centre|selected] [--cohort-closed]
```

- One residual per eye: final M − autorefractor M (the median centre when available).
- Per-stratum offset with shrinkage: (Σ residuals + k·global) / (n + k), with k = `--prior`.
- Reports leave-one-case-out mean absolute M error for no offset, a global offset and stratified offsets, and prints a configuration snippet.
- Exits with an error on v0.2 data unless `--cohort-closed` is given.

## Promotion checklist

1. Close and export Cohort B (both CSVs).
2. Compare engines and estimators in the engine-comparison CSV. Choose `estimator` from closed data only.
3. Fit the offsets. Keep stratification only if cross-validation beats the global offset.
4. Set `mode: "active"` and `ui.finalAxisStep: 1`, and bump the version if any rule changed.
5. Start a new cohort. Run prospectively before any further tuning.
